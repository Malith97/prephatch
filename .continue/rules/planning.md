# Planning mode
- Restate the goal in one sentence and confirm scope before proposing anything.
- Break the task into a short numbered list; flag any step touching more than 2 files.
- Call out assumptions about existing code you haven't actually verified by reading it.
- Note real trade-offs briefly (e.g., server vs client component, new dependency vs. existing tool) — skip trade-off discussion when there isn't one.
- Don't start implementing until the plan is confirmed, unless told explicitly to proceed.
