# Tech Stack

Status: Proposed  
Owner: Founder  
Last Updated: 2026-04-06  
Purpose: Defines the preferred stack for MVP.

## Recommended Stack

- Frontend/App: Next.js
- Language: TypeScript
- Styling: Tailwind CSS
- Database/Auth/Storage: Supabase
- Payments: Stripe
- Hosting/Edge/CDN: Cloudflare + managed hosting path
- Runtime AI: OpenAI or multi-provider router with strict controls
- CI: GitHub Actions
- Testing: Vitest + Playwright

## Selection Criteria

- low cost
- reliable ecosystem
- fast setup
- good DX for AI-assisted coding
- scalable enough for early growth

## Stack Rule

Do not introduce additional major platforms unless they solve a clear problem that existing tools cannot solve cost-effectively.
