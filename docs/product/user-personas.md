# User Personas

Status: Active  
Owner: Founder  
Last Updated: 2026-04-06  
Purpose: Defines the main user groups and their needs.

## Primary Personas

### 1. Working Professional
- Time-poor
- Wants realistic practice and quick confidence signals
- Values concise, trusted explanations

### 2. Career Switcher
- Needs structure
- Wants explanations that teach concepts, not just answers
- May need confidence-building through repetition

### 3. Retake Candidate
- Wants to identify weak areas fast
- Expects realistic exam simulation
- Highly sensitive to question quality and trust

### 4. Beginner / Student
- Needs simpler explanations and reinforcement
- Benefits from notes and revision aids

## Shared Pain Points

- fragmented resources
- poor explanation quality
- unclear readiness signal
- low trust in existing prep sources
