# Launch Plan

Status: Active  
Owner: Founder  
Last Updated: 2026-04-06  
Purpose: Defines the path from planning to first launch.

## Phase 1 — Core Value

Goal: user can complete a free mock and see trusted results.

## Phase 2 — Monetization

Goal: user can buy the package and unlock premium mocks.

## Phase 3 — Reliability Hardening

Goal: test payments, entitlements, timing, and submission flows thoroughly.

## Phase 4 — Controlled Launch

Goal: soft launch to a small group before wider promotion.

## Launch Gate

Do not launch until all of the following are true:
- free mock works end to end
- premium access works end to end
- entitlement expiry works
- exam timer rules are validated
- AI failure does not break results
- smoke checks and core E2E tests pass
