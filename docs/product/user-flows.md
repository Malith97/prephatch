# User Flows

Status: Active  
Owner: Founder  
Last Updated: 2026-04-06  
Purpose: Defines the main user journeys.

## Primary Conversion Flow

1. Visitor lands on homepage or package page.
2. User signs up or logs in.
3. User starts free mock.
4. User completes exam.
5. User sees results and upgrade path.
6. User purchases package.
7. User enters purchased workspace.

## Practice Mode

- answer one question
- check answer
- see explanation immediately
- see wrong-answer reasoning
- answer locks after checking
- continue

## Timed Mode

- attempt begins immediately
- deadline is server-controlled
- no pause
- no explanation during attempt
- question palette and flagging available
- unanswered warning before final submit
- auto-submit on timeout

## Purchased Workspace

Includes:
- premium mocks
- recent attempts
- progress summary
- notes
- cheatsheets

## Admin Flow

Admin can:
- create and edit questions
- assemble mocks
- publish and archive content
- manage notes and cheatsheets
- import draft content
