# MVP Scope

Status: Active  
Owner: Founder  
Last Updated: 2026-04-07  
Purpose: Defines what is included, excluded, and sequenced for launch.

## Launch Now

| Area | Included |
| --- | --- |
| Certification | One certification only: AWS SAA-C03 |
| Entry surfaces | Public homepage, logged-in dashboard, single package detail page |
| Auth | Email/password, Google login |
| Free loop | One free mock after login |
| Paid loop | 2 to 3 premium mocks behind entitlement |
| Exam engine | Practice mode, timed mode, autosave, resume-before-deadline |
| Results | Score summary, readiness label, topic breakdown, per-question review |
| Explanations | Stored base explanation and wrong-answer reasoning |
| Commerce | One-time purchase, Stripe checkout, 365-day entitlement |
| Admin | Minimal question and mock content operations |
| AI | Optional on-demand deep explanation after review |

## Launch Soon After

| Area | Later |
| --- | --- |
| Analytics | Richer progress charts and trend views |
| Resources | Broader notes and cheatsheets library |
| Commerce | Coupons, near-expiry reminders, renewal campaigns |
| Admin | Better workflows and bulk content tooling |

## Not MVP

| Area | Excluded |
| --- | --- |
| Auth | Facebook login |
| Commerce | Subscriptions |
| Product | Live AI tutoring, mobile app, team accounts |
| Compliance | Advanced proctoring |
| Expansion | Multilingual support, heavy analytics suite |

## Scope Rule

If a feature does not improve launch value, reliability, or revenue, defer it.
