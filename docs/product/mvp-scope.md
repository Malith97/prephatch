# MVP Scope

Status: Active  
Owner: Founder  
Last Updated: 2026-04-06  
Purpose: Defines what is included, excluded, and sequenced for launch.

## Launch-Critical

- email/password auth
- Google login
- one package detail page
- one free mock exam after login
- 2 to 3 premium mock exams
- practice mode
- timed mode
- result and review page
- one-time payment
- 365-day entitlement
- minimal admin content tools
- optional on-demand AI deep explanation

## Launch-Soon-After

- richer progress charts
- coupons
- better content tooling
- expanded notes and cheatsheets
- near-expiry reminders

## Explicitly Out of MVP

- Facebook login
- subscriptions
- mobile app
- team accounts
- live AI tutoring
- advanced proctoring
- multilingual support
- heavy analytics suite

## Scope Rule

If a feature does not improve launch value, reliability, or revenue, defer it.
