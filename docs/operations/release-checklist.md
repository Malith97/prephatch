# Release Checklist

Status: Active  
Owner: Founder  
Last Updated: 2026-04-06  
Purpose: Checklist for safe releases.

## Before Release

- CI green
- migrations reviewed
- preview environment verified
- critical docs updated
- smoke checklist prepared

## After Release

- homepage works
- auth works
- free mock works
- premium gate works
- payments work
- AI fallback works
- logs show no critical errors
