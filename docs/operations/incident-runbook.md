# Incident Runbook

Status: Draft  
Owner: Founder  
Last Updated: 2026-04-06  
Purpose: Defines a simple incident response process.

## Steps

1. identify issue
2. assess severity
3. contain harm
4. fix or apply workaround
5. verify recovery
6. record follow-up action

## High-Severity Areas

- payment failures
- entitlement failures
- exam submission failures
- admin publish mistakes
- major auth outage
